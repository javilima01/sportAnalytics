## Description

This project provides a complete framework for training YOLO models using **Ultralytics** with integrated tools for **dataset generation** and **label management**. It includes a module for **automatic pseudo-labeling** that uses a pretrained YOLO model to label images directly from YouTube videos. By specifying a video URL, a time interval, and a confidence threshold, the system downloads the video, extracts the relevant frames, and assigns labels automatically.

In addition, the toolkit offers a **manual labeling interface** that allows users to review and adjust pseudo-labels through an intuitive UI. This combination of automated and human-assisted labeling enables efficient dataset creation and model improvement with minimal effort.
